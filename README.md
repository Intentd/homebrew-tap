# Homebrew tap for Inrun

Homebrew formulas for [Inrun](https://github.com/inrundev/inrun), the intent runner for Kubernetes, and its console.

## Install

```bash
brew install inrundev/tap/inrun
brew install inrundev/tap/inrun-console   # optional: the console
```

## Verify

```bash
inrun version
```

## Upgrade

```bash
brew update && brew upgrade inrun inrun-console
```

## How this tap is updated

The formulas in `Formula/` are generated by the Inrun release workflow, with checksums from each release. Don't edit them by hand; changes belong in the [main repository](https://github.com/inrundev/inrun).
